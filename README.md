A neon breakout game built from a single prompt by an AI agent. One prompt in — paddle, ball, colourful bricks, score, lives, keyboard and mouse control, game over and restart — and a playable game out, no libraries, no code typed by hand. The video on X shows the prompt, the agent writing `game.html`, and the finished game running for real. This repository holds the game and the X post that enters make.fun's "The agent builds a game from one prompt" bounty.

## Run it

```sh
python3 -m http.server 8000
# then open http://localhost:8000/game.html — click or press Space to launch the ball
```
